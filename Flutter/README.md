# Flutter Hackathon Project – Starter Girl Hack 2025

This directory contains a **Flutter-based mobile application prototype** developed during the **Starter Girl Hack** hackathon.

The project was created within a **48-hour hackathon sprint (June 24–25, 2025)** organized by **Inkubator STARTER** and led by **Alicja Świtlik**.

---

## Project Context

The hackathon brought together 20 participants working in teams to develop MVP solutions addressing real-world challenges across four thematic areas:
- STEM in everyday life  
- Creativity + Code – TechArt & Design  
- Green Future  
- Girls Who Code for Change  

---

## Project Overview

As part of my team, I contributed to the development of a prototype for the **"Women in STEM" website and mobile application**.

The goal of the project was to design a **supportive platform for women interested in STEM**, focused on:
- fostering personal and professional growth  
- building a sense of community  
- encouraging motivation and collaboration  

The concept was supported by:
- basic data analysis
- a financial plan
- a visual presentation prepared in Canva
