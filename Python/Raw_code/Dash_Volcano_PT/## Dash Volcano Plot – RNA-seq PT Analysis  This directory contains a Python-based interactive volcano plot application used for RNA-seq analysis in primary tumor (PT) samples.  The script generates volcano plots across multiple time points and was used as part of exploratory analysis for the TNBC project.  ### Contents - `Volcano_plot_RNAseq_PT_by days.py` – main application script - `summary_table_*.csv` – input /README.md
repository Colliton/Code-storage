## Dash Volcano Plot – RNA-seq PT Analysis

This directory contains a Python-based interactive volcano plot application
used for RNA-seq analysis in primary tumor (PT) samples.

The script generates volcano plots across multiple time points and was used
as part of exploratory analysis for the TNBC project.

### Contents
- `Volcano_plot_RNAseq_PT_by days.py` – main application script
- `summary_table_*.csv` – input / output data used by the app
- `requirements.txt` – Python dependencies
- `runtime.txt` – runtime configuration for deployment
