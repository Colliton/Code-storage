## Python Projects Overview

This directory contains Python-based data analysis projects.

The main body of work focuses on **biomedical data analysis related to
Triple Negative Breast Cancer (TNBC)** and includes exploratory and statistical
analyses implemented both as Jupyter notebooks (with rendered outputs)
and as standalone Python scripts.

Some of the TNBC analyses were used to prepare a scientific poster
(Poster_session_2025), while others represent additional exploratory work.

The directory also includes **Additional_projects**, which contain smaller,
independent Python scripts and experiments unrelated to the TNBC analysis.
