# SQL Projects

This directory contains SQL-based database design and analysis projects, with a strong focus on **PostgreSQL**, relational modeling, and analytical querying.

The main project in this section is a fully structured **Clinical Trial database**, designed and implemented as an end-to-end SQL solution.  
Additional standalone SQL scripts are also included.

---

## Clinical Trial Database

**Clinical_Trial/** contains a comprehensive PostgreSQL database project modeling a clinical trial domain.

The project covers the full database lifecycle:
- conceptual, logical, and physical data modeling
- DDL scripts with constraints and relationships
- sample data inserts
- reusable functions and triggers (PL/pgSQL)
- analytical views and queries
- role-based access control and Row-Level Security (RLS)
- rerunnable test scripts for functions and views

This project was designed with an emphasis on:
- data integrity
- clear schema organization
- production-style SQL structure
- analytical usability

➡️ See the `Clinical_Trial/README.md` for detailed documentation.
