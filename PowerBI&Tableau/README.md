# Power BI & Tableau Projects

This directory contains data visualization projects created using **Power BI** and **Tableau**.

The projects focus on exploratory data analysis, reporting, and dashboard design, with an emphasis on clarity, usability, and business-oriented insights.

Each subdirectory contains a short project description and links to public dashboards where applicable.

## Structure
- **PowerBI/** – interactive dashboards created in Power BI
- **Tableau/** – visual analytics projects built in Tableau
